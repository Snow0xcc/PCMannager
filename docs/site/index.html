功能模块

剪贴板历史

文本、图片、文件流多态存储，图片与文件只存路径避免数据库膨胀。

截图与录屏

区域截图、GIF 录屏、滚动长截图，支持矩形、椭圆、箭头、画笔、马赛克、文本、水印。

任务栏状态

网速、内存、电量等，透明背景 + 反色文字，定位锚在通知区左侧。

快捷面板

Alt+Space 全局搜索，多因子加权排序，支持别名与拼音缩写。

超级面板

Alt+P 悬浮磁贴池，高频命令一键执行，失焦隐藏。

电脑修复

一键安装工具箱，条目声明式集中管理，支持 winget / choco 偏好。

上下文记录

定时截屏结合窗口标题，可接视觉语言模型解析画面语义（默认关闭）。

自动更新

静默检查与镜像池轮询下载，应用需显式确认（默认关闭）。

构建

bash scripts/build.sh windows amd64 pcmannager.exe

该脚本固定 -tags production 并对 Windows 追加 -H windowsgui。直接 go build 会因缺少构建标签导致程序静默退出。
