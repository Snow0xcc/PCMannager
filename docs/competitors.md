# 竞品分析（Competitive Analysis）

## 概述（Synthesis）

PCMannager 是一款面向 Windows 桌面的系统增强工具，其设计思路并非从零构建，而是借鉴了四款成熟参考产品的优秀范式并加以整合。它从 **Snipaste** 借用了区域/窗口/全屏截图、像素级缩放、取色器、截图置顶（pin 为浮动窗口）、标注与历史记录、F1 热键及多显示器支持，并计划引入 OCR；从 **Ditto** 借用了统一的剪贴板历史（文本/图片/文件/HTML）、搜索、双击或热键粘贴、分组、自定义格式、跨机同步、置顶条目与插件；从 **TrafficMonitor** 借用了浮动网速与 CPU/RAM 显示、任务栏注入、可定制文字/颜色、流量历史曲线、天气、多网卡与插件及悬浮提示图；从 **uTools** 借用了插件生态、快速启动（Alt+Space）、剪贴板/截图/取色插件、JSON/翻译/换算工具，以及「万物皆插件」与跨插件数据共享理念。通过将这些能力收敛到单一工具中，PCMannager 试图以更低的使用与维护成本，提供一致而连贯的桌面效率体验。

## 差异化建议（Differentiation Suggestions）

- **统一热键配置中心**：将 Snipaste 的 F1、Ditto 的全局热键、uTools 的 Alt+Space 收敛到一处可集中管理的热键设置，避免冲突。
- **Go 单文件分发**：以 Go 编译为单一二进制（single binary），免安装、体积小、启动快，降低 Windows 桌面工具的部署与维护成本。
- **按功能模块开关（per-feature toggle）**：各能力（状态栏、剪贴板、截图、上下文）可独立启停，用户只加载需要的部分，保持轻量。
- **轻量化优先**：在吸收四款参考产品能力的同时，避免功能膨胀，控制内存与常驻资源占用，主打「够用且轻盈」。
- **跨功能数据联动**：参考 uTools 的跨插件数据共享，让截图、剪贴板与上下文记录之间可互相引用，形成统一的工作流而非孤岛。
- **本地优先 + 可选同步**：默认本地存储（隐私优先），仅在用户显式开启时提供 Ditto 式的跨机同步能力。
