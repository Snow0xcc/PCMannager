# 快捷键

## 全局热键

| 热键 | 功能 |
| :--- | :--- |
| Alt+Space | 唤起快捷面板 |
| Alt+P | 唤起超级面板 |
| F1 | 截图 |
| Ctrl+` | 剪贴板历史 |
| Ctrl+Alt+T | 任务栏状态统计 |
| Ctrl+Alt+M | 上下文记录（需先启用模块） |
| Ctrl+Shift+A | 滚动截图 |
| Alt+Shift+R | 录屏（GIF） |

热键可在设置面板中改绑。若某热键被其它程序占用（Alt+Space 常被 PowerToys Run 等占用），注册会失败并在面板显示冲突提示——改绑即可。

## 快捷面板内操作

| 按键 | 行为 |
| :--- | :--- |
| 输入字符 | 实时过滤候选 |
| Backspace | 删除字符 |
| 左右方向键 | 移动高亮候选 |
| 鼠标滚轮 | 横向滚动候选条 |
| Enter | 执行高亮候选 |
| Esc | 关闭面板 |
| 点击候选 | 执行该候选 |
| 点击右上角图钉 | 切换"固定到前方" |
| 右键候选 | 弹出操作菜单 |

面板失焦自动隐藏。

## 快捷面板右键菜单

按候选类型呈现不同项：

- 公共项：固定/取消固定到前方、编辑关键字
- 本地应用/文件/文件夹：复制文件路径、打开文件位置、固定到超级面板
- 可执行类（`.exe` `.bat` `.cmd` `.ps1` `.lnk`）：以管理员身份运行
- 文件夹：在终端打开此处
- 空白处：清空排行榜

## 超级面板

- Alt+P 唤起；单击磁贴执行，右键移出，失焦隐藏
- 在快捷面板右键菜单选"固定到超级面板"加入条目

## 截图编辑器

| 按键 | 行为 |
| :--- | :--- |
| Enter | 保存到剪贴板并关闭 |
| Esc | 取消 |
| C | 复制到剪贴板 |

工具栏支持矩形、椭圆、箭头、画笔、马赛克、文本、水印、撤销；录屏为 GIF 格式，滚动截图支持手动/自动滚动拼接。
