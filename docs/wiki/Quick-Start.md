# 快速开始

## 安装

1. 从 [首页](Home.md) 的下载表选择对应平台产物。
2. Windows：直接运行 `pcmannager-windows-amd64.exe`（GUI 子系统，无控制台窗口）。
3. Linux / macOS：赋予执行权限后运行。

程序以托盘常驻方式工作，启动后不一定弹出窗口——请查看系统托盘区。

## 首次配置

配置文件位于系统配置目录（Windows 为 `%APPDATA%\GoBox\config.yaml`），启动时自动生成并填充默认值。

可用环境变量 `PCMANNAGER_CONFIG` 覆盖配置目录，便于调试：

```bash
export PCMANNAGER_CONFIG=/path/to/dir
```

## 打开设置面板

托盘图标右键菜单中选择打开面板；或程序内按快捷键唤起（见 [快捷键](Hotkeys.md)）。面板仅监听 `127.0.0.1`，通过浏览器访问。

## 日志

日志同时写入两处：

- 数据目录 `logs/gobox.log`
- 程序所在目录 `logs/gobox.log`（随可执行文件走，便于无控制台的 GUI 构建就地排查）

日志文件按 8 MiB 上限轮转，保留 3 个备份。

## 模块开关

每个模块可在面板中独立启停。默认启用：剪贴板、截图、修复、任务栏、快捷面板。默认关闭：上下文记录（涉及屏幕内容，隐私敏感）、自动更新。
